# GameShift 0.5.0-alpha.2-20261114

GameShift 0.5.0-alpha.2 — édition du 14 novembre 2026.

Cette préversion actualise l’accueil adaptatif, la navigation et le tableau de bord Aurelia. Elle comprend les améliorations de découverte des capteurs, du suivi des moteurs GPU, de la ventilation et des relevés CPU RAPL selon les interfaces disponibles.
